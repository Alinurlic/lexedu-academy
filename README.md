# LexEdu Academy — ЕНТ · SAT · IELTS

Платформа подготовки к **ЕНТ (ҰБТ)**, **Digital SAT** и **IELTS Academic** с маскотом **Lexi**: полноформатные пробные экзамены по регламенту, практика по темам, банк заданий, тетрадь ошибок, Writing & Speaking студия, умный анализ, ИИ-помощник, геймификация и админ-панель.

Интерфейс на русском. Без настроек приложение работает локально (LocalStorage, Lexi в демо-режиме). С Supabase и ключом ИИ на Vercel появляются регистрация с подтверждением email, облачный прогресс и полноценный ИИ.

## Публикация на Vercel (пошагово)

### 1. Supabase — аккаунты и база

1. Создайте проект на [supabase.com](https://supabase.com).
2. **SQL Editor → New query** → вставьте весь `supabase/schema.sql` → **Run**.
3. **Authentication → Sign In / Providers → Email**: включите **Confirm email**. Так аккаунт активируется только после перехода по ссылке из письма, и пустые аккаунты не создаются.
4. **Authentication → URL Configuration**:
   - *Site URL*: `https://<ваш-проект>.vercel.app`
   - *Redirect URLs*: `https://<ваш-проект>.vercel.app/**` (и `http://localhost:5173/**` для разработки)
5. **Project Settings → API**: скопируйте *Project URL* и *anon public* ключ. Это публичные значения.
6. (Рекомендуется) Свой SMTP в **Authentication → Emails → SMTP Settings**. Встроенная почта Supabase отправляет лишь несколько писем в час.
7. (Необязательно) Защита от ботов: **Authentication → Attack Protection → Captcha → Cloudflare Turnstile** (секретный ключ). Site key укажите в `VITE_TURNSTILE_SITE_KEY`.

### 2. GitHub → Vercel

1. Загрузите проект в репозиторий GitHub.
2. [vercel.com](https://vercel.com) → **Add New → Project** → импортируйте репозиторий. Настройки сборки берутся из `vercel.json` (Vite, `npm run build`, `dist`).
3. **Settings → Environment Variables**:

| Переменная | Значение | Секрет? |
|---|---|---|
| `VITE_SUPABASE_URL` | Project URL из Supabase | нет |
| `VITE_SUPABASE_ANON_KEY` | anon public key | нет |
| `ANTHROPIC_API_KEY` | ключ с [console.anthropic.com](https://console.anthropic.com) | **да**: только здесь, никогда в коде и без префикса `VITE_` |
| `AI_DAILY_LIMIT` | запросов к ИИ на ученика в сутки, по умолчанию `60` | нет |
| `LEXI_MODEL` | модель Claude, по умолчанию `claude-opus-5-5` | нет |
| `VITE_TURNSTILE_SITE_KEY` | site key Cloudflare Turnstile (необязательно) | нет |

4. **Deploy**. После изменения переменных нажмите **Redeploy**: `VITE_*` попадают в сборку.

### 3. Назначить администратора

Зарегистрируйтесь на сайте, затем в Supabase SQL Editor:

```sql
update public.profiles set role = 'admin'
where id = (select id from auth.users where email = 'ваш@email');
```

## Как устроены аккаунты

- Регистрация: email и пароль (8+ символов, буквы и цифры). Supabase отправляет письмо, войти можно только после подтверждения. Ссылку можно отправить повторно.
- Восстановление пароля по ссылке из письма.
- После первого входа идёт **анкета**: имя, класс, экзамены (ЕНТ / SAT / IELTS), профильные предметы ЕНТ, **текущий уровень**, **последний результат** (или «ещё не сдавал»), цель и дата экзамена. Всё это можно изменить в «Настройках» или пройти анкету заново.
- Прогресс синхронизируется в таблицу `user_state` (RLS: каждый видит только свои данные). Роль `admin` пользователь не может выдать себе сам.

## ИИ (Lexi)

Серверная функция `api/lexi.ts` (Vercel Function) обращается к Claude. Ключ хранится только на сервере.

- **Чат-тьютор**: объясняет, получает сводку статистики ученика.
- **Проверка IELTS Writing/Speaking** по 4 критериям с band и разбором на русском.
- **Умный анализ**: персональный план на неделю.
- **Генерация заданий** для админа: сохраняются со статусом «Требует проверки».

Защита: ИИ доступен только вошедшим пользователям с подтверждённым email, действует дневной лимит (таблица `ai_usage`). Без Supabase функция отключена, чтобы никто посторонний не тратил ключ. Для локальной разработки есть `AI_ALLOW_ANONYMOUS=1`.

Без ключа Lexi работает в демо-режиме, и интерфейс это явно показывает: пошаговый решатель уравнений, генератор задач с вычисленными ответами, разбор ошибок. IELTS Writing в этом режиме оценивается самооценкой по критериям.

## Экзамены по регламенту

| Экзамен | Структура |
|---|---|
| **ЕНТ** | 120 заданий, 240 минут, 140 баллов. История Казахстана 20, мат. грамотность 10, грамотность чтения 10, 2 профильных предмета × 40 (25 с одним ответом + 5 контекстных по 1 баллу, 5 на соответствие + 5 с несколькими ответами по 2 балла; одна ошибка → 1 балл). 11 комбинаций профильных предметов. Формат меняется в админ-панели |
| **Digital SAT** | Reading & Writing: 2 модуля × 27 (по 32 мин). Math: 2 модуля × 22 (по 35 мин). Перерыв 10 мин. Второй модуль адаптивный (≥60% → сложный). Шкала 400–1600 **приблизительная**: официальная использует IRT |
| **IELTS Academic** | Listening 4 части / 40 вопросов (озвучка синтезатором речи, звучит один раз), Reading 3 текста / 40 вопросов / 60 мин, Writing Task 1 + Task 2 / 60 мин. Перевод в band по таблицам, overall с официальным округлением. Speaking — в студии с распознаванием речи |

Типы заданий: один ответ, несколько ответов, соответствие, число, краткий ответ, верно/неверно, эссе.

**Источники:**
- `demo` — собственные задания LexEdu (написаны для проекта, часть собрана генераторами с вычисляемыми ответами);
- `open` — открытый источник с лицензией. Сейчас это **KazMMLU (MBZUAI, CC BY-NC 4.0)**: подробности, авторы и ограничения — в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Ссылка на первоисточник показывается в разборе каждого задания. Банк грузится фоном по предметам (`src/data/questions/open/`), импорт — `scripts/import-kazmmlu.py`;
- `verified` — официальные материалы, добавляются через **Админ-панель → Импорт JSON** с обязательной ссылкой на источник;
- `user` — задания, добавленные пользователем.

В заданиях ЕНТ варианты ответов перемешаны детерминированно, чтобы правильный ответ не стоял на одной позиции.
